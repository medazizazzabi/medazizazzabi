# Mohamed Aziz Azzabi

**Software engineer, backend and DevOps. I build systems, ship them, and keep them running in production.**

I'm co-founder of **Azifir**, where I build and operate point-of-sale software used by five businesses in Tunisia and France. I write the code, run the release pipeline, and handle production when something breaks.

## What I work on

Most of my work is client production code, so the repositories are private.

- **Rigla**: point-of-sale and inventory platform for retail shops, built with Python (Flask), Next.js and PostgreSQL. It runs at four clients; the largest processes around 500 transactions a day. It started as microservices on Kubernetes and is now a modular monolith on Docker Compose. Releases go through GitHub Actions: tests against a real PostgreSQL, Playwright end-to-end tests on staging, then a gated rollout to each client.
- **Dhiyafa**: restaurant point-of-sale in TypeScript (Node.js, React, PostgreSQL), with an in-store hub that keeps selling without internet.
- **Omnipoint**: my engineering graduation project, an ERP and point-of-sale system made of Flask microservices. A Jenkins pipeline (SonarQube, Gitleaks, Trivy) deploys it with Helm to Kubernetes on Google Cloud, provisioned with Terraform.

## Public projects

- **[ThatWay](https://github.com/medazizazzabi/ThatWay)**: community-driven public transport tracker, where passengers share their live location so others get arrival estimates. Symfony web app with a JavaFX desktop client. Team project at ESPRIT.
- **[PDFClassifier](https://github.com/medazizazzabi/PDFClassifier)**: extracts and classifies data from PDF documents with Tesseract OCR, K-means and YOLOv8, served through a Flask web service in Docker.
